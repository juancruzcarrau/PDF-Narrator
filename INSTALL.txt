PDF Narrator — installation
===========================

Requires macOS 14 (Sonoma) or later. Works on Apple Silicon and Intel Macs.

1. Drag "PDF Narrator" into the Applications folder.

2. First launch only: the app isn't signed with a paid Apple developer
   certificate, so macOS will block it the first time.
     • Double-click PDF Narrator. When macOS says it can't be opened, click "Done".
     • Open System Settings → Privacy & Security, scroll down, and click
       "Open Anyway" next to the PDF Narrator message. Confirm with your password.
   After that it opens normally.

   (Alternative, in Terminal:  xattr -dr com.apple.quarantine "/Applications/PDF Narrator.app")

Using it
--------
• Drop a PDF on the window (or ⌘O). Click any word in the text to start reading there.
• If the PDF has chapters (bookmarks), they appear in a sidebar: click one to jump there.
  The sidebar button next to ⋯ shows or hides it.
• Next to the progress bar: how long the document takes to read, then the time left.
• Space / keyboard play-pause key / AirPods: play & pause. ⌘← ⌘→ or ⏪ ⏩: previous/next paragraph.
• ⋯ menu → Voice: "System Voice" uses the voice chosen in
  System Settings → Accessibility → Spoken Content (including Siri voices).
  Download better voices there under System Voice → Manage Voices.

Updates
-------
When a new version is out, an "Update" bar appears at the top of the window.
Click it: the app downloads the new version, replaces itself and reopens.
(Keep the app in the Applications folder so it can update itself.)
